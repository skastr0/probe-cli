# Contributing

Probe is an experimental, solo-maintained project. Issues are the default contribution path: reproducible bug reports, scoped proposals, and documentation corrections are the most useful inputs.

## What Helps

- Reproducible bug reports
- Documentation corrections
- Scoped proposals before implementation work
- Small fixes with tests or clear verification notes, when they are tied to an accepted issue or obvious documentation problem

## What Is Out Of Scope

- Large rewrites without prior discussion
- Broad feature work that changes the maintenance burden substantially
- Public security reports; use the private reporting path in SECURITY.md

## Local Workflow

Use the commands documented in README.md for this repository. If a pull request is appropriate, run `bun run verify` and include the result in the PR description.

## Pull Requests

External pull requests are not the default path. Small, focused PRs may still be considered when they follow an accepted issue, fix an obvious documentation problem, or reduce maintenance risk. A PR may be declined for scope, maintenance cost, compatibility risk, or product direction even when the implementation is technically sound.
